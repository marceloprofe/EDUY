# EDUY– Plataforma educativa

Plataforma educativa para cursos asincrónicos.

- Wilson Llaguna — Scrum Master
- Rubén Acuña — Desarrollo y pruebas

## Flujo de trabajo Git

- `main`: versión estable y entregable.
- `develop`: integración del trabajo del sprint.
- `feature/*`: trabajo de cada tarea concreta.
- Está prohibido trabajar o realizar commits directamente sobre `main`.
- Todo cambio debe realizarse en una rama `feature/*`, integrarse mediante pull request a `develop` y llegar a `main` únicamente después de revisión.
- Cada pull request debe estar vinculado con una issue y cumplir sus criterios de aceptación.

## Plan general

1. Sprint 1: descubrimiento, requisitos y planificación.
2. Sprint 2: prototipo, arquitectura y modelo de datos.
3. Sprint 3: desarrollo de las funciones principales.
4. Sprint 4: pruebas, evidencias y entrega final.
