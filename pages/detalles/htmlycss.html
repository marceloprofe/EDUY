Desarrollo web

HTML y CSS desde cero

Aprendé a crear páginas web modernas, accesibles y adaptables a diferentes dispositivos.

Instructor: Equipo EDUY

Modalidad: Curso en línea y asincrónico

Nivel: Inicial

Duración estimada: 20 horas

Volver al catálogo

Descripción del curso

Este curso introduce los fundamentos necesarios para construir sitios web utilizando HTML y CSS. A través de actividades prácticas, el estudiante aprenderá a organizar contenidos, aplicar estilos y crear diseños adaptables.

¿Qué aprenderás?

  • Estructura básica de una página web.
  • Etiquetas semánticas de HTML.
  • Selectores y propiedades de CSS.
  • Diseño responsive con Bootstrap.
  • Buenas prácticas de accesibilidad.
